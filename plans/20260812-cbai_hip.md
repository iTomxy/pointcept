# Goal

Implement for the cbai-hip dataset, then train & test with PointTransformerV3 on it.

# Data

- (raw & preprocessed) data, splitting, statistics, etc.: data/cbai_hip/
- implementation: pointcept/datasets/cbai_hip/

# Config

Put under configs/cbai_hip/.

# Env

- This is a gpu server (hostname: `strax-server2`). Use them directly.
- Run with the docker image built for pointcept. Docker is available on this server. See [dock.sh](../dock.sh) and [cu128_pt271.Dockerfile](../containers/cu128_pt271.Dockerfile).
- screen and tmux are available. Use if needed, e.g. host long commands with a session in background.
- Use ~/mail.sh to inform me on events, e.g. finishing something, or meeting something you cannot determine and need to discuss with me.
- Create any `tmp-ai*.py` or `tmp-ai*.sh` if needed. They are ignored by git.

# Notes

- Always use sync_bn when multiple GPUs are used.
